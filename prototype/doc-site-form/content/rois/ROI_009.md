| 光学窗口所在行 | 偏移 dx（像素） |

| 3072 ~ 5632 | 一对都没找到 |
| 6144 ~ 8704 | +88 ~ +128 |
| 9216 ~ 14848 | −96 ~ −108 |
| 15360 ~ 17920 | −188 ~ −216 |
| 18432 ~ 24064 | −64 ~ +36 |
