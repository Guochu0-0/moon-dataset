波段

混合极化：发射圆极化，相干接收 H、V 两路线极化。4 个 float32 波段，按波段顺序存放（SIS §4.3.2.2.1）。

波段 BAND_NAME 物理量
1 H RECEIVE INTENSITY ⟨|EH|²⟩，功率
2 V RECEIVE INTENSITY ⟨|EV|²⟩，功率
3 CROSS POWER INTENSITY (REAL) Re⟨EH EV*⟩
4 CROSS POWER INTENSITY (IMAGINARY) Im⟨EH EV*⟩

波段 3、4 可为负值。

Stokes 参数

SIS §4.3.2.2.1–2：

S1 = b1 + b2
S2 = b1 - b2
S3 = 2 * b3
S4 = -2 * b4

SC  = 0.5 * (S1 - S4)                        # 同向圆极化
OC  = 0.5 * (S1 + S4)                        # 反向圆极化
CPR = SC / OC                                # 圆极化比
m   = np.sqrt(S2**2 + S3**2 + S4**2) / S1    # 极化度

全月平均 CPR 约 0.3，m 约 0.6（SIS §4.3.2.2.2.3）。
