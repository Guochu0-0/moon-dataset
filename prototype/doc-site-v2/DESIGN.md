# 原型：文档站的视觉设计（PROTOTYPE，一次性）

主题：CE-2 光学 × Mini-RF SAR 的月面配准数据集。读者：作者、课题组同学、老师。
页面的主要任务：一眼看懂数据集是什么、在月面哪里、长什么样；再能查到事实。

共用的数据编码（两个方向一致）：划分用颜色区分。

| 划分 | 地图上 | 表格色块 |
|---|---|---|
| 训练集 | `#F2F4F6`（带暗描边，压在月面灰上可见） | `#8C96A1` |
| 验证集 | `#2E7BD6` | 同左 |
| 测试集 | `#E39B1B` | 同左 |

## A 月面图集（地图优先）

- 颜色：纸 `#E9ECEE`（冷灰，取月尘色，不用暖米色）、墨 `#1B2733`、次墨 `#55616D`、分隔 `#C9CFD4`、地图框 `#1B2733`。
- 字体：IBM Plex Sans（拉丁、数字）+ 系统黑体（Noto Sans SC / 微软雅黑）；产品 ID、路径用 IBM Plex Mono。
- 版式：首页开头是通栏全月地图，画出 67 条 ROI 条带和经纬网，悬停出条带缩略图，点击进 ROI 页。
  地图下方是标题、简介、划分表，再往下是样例配对，悬停某个真值点，另一侧对应的点同时高亮。
  ROI 总表：地图与表格联动（悬停行高亮条带，反之亦然），可按划分筛选。
  ROI 页：左侧是定位小图和参数，右侧是光学、SAR 两条缩略图，叠加 patch 网格，带真值点的格子着色。

```
┌───────────────────────── 全月地图（通栏）─────────────────────────┐
│  ▯   ▯ ▯      ▯  ▯        ▯     ▯        ▯   ▯       ▯             │
└────────────────────────────────────────────────────────────────────┘
 标题 + 一段话                 │ 划分 │ ROI │ patch 对 │ 真值点 │
 ── 样例 ──  [光|SAR] [光|SAR] [光|SAR] [光|SAR]
```

## B 配对图版（图优先）

- 颜色：纸 `#FFFFFF`、墨 `#16181D`、次墨 `#6B7079`、图版 `#2A2D33`（看片灯箱的石墨色）、图版上的字 `#E8E9EB`、链接 `#2451B3`。
- 字体：Source Serif 4（拉丁、数字，表格用等宽数字）+ 系统宋体（Noto Serif SC / 宋体）。
- 版式：图都放在石墨色图版上，按「图 1、图 2」编号（文档里的图本来就是顺序）。
  首页开头是一对光学/SAR patch，真值点跨过中缝连线，下方是 13 对样例的胶片条，点选切换。
  全月地图用圆点表示 ROI 中心，面积与 patch 对数成正比。
  ROI 总表做成缩略图墙：每个 ROI 一对细长条带，按划分分组。
  ROI 页：整条条带竖着贴在左边作为页面脊柱（随页滚动固定），右边是文字和参数。

```
┌─────────── 图版 ───────────┐
│  [ 光学 512 ] ╲╱ [ SAR 512 ] │
└─────────────────────────────┘
 图 1　ROI_007 第 138 对……
 ▢▢▢▢▢▢▢▢▢▢▢▢▢  胶片条
```

## 自查（对照常见默认做法）

- 没用暖米色底 + 陶土色强调；A 用冷灰纸，B 用白纸 + 石墨图版。
- 没用近黑底 + 单一荧光强调。地图框是深蓝灰，颜色只用来编码划分。
- 不用全大写小标签、不在标题上加眉题、不用「A · B · C」式的中点串联；原 ROI 页副标题的中点串改成分开的字段。
- 编号只出现在 B 的「图 n」上。
- 大胆的地方只放一处：A 是通栏地图，B 是跨中缝的真值点连线。其余保持安静。
- 动效只有一处：B 首页切换样例时连线重画。悬停高亮是对操作的响应。
