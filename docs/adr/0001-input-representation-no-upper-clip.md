# 输入表示：S1 取 dB，下限夹到噪声底，上限不截断，全局标准化

SAR 的输入表示取总功率 S1 = b1 + b2 的 dB 值，先夹到 −25 dB（Mini-RF 噪声等效后向散射系数，SIS 表 1 标称值）以上，再用只取自训练集的全局常数标准化（μ = −10.976 dB，σ = 2.711 dB）；光学同样用训练集常数全局标准化（μ = 73.786，σ = 26.533）。不截上限、不逐 patch 归一化，是有意偏离常见做法：全像素统计表明高端（z 最大约 8.2）全是正对雷达的坑壁、石块等真实结构，常见的 p0.5–p99.5 截断会截掉训练集约 1% 的像素、单个 patch 最多 74%；数据集里唯一的极端值来自近零的重采样过冲，下限一夹就消除。逐 patch 归一化会抹掉条带间约 1 dB 的定标差异，也抹掉月海与高地的真实亮度差；数据集应如实交付这些差异，要不要对它不敏感是训练时的选择（例如随机 dB 偏移增强）。

## Considered Options

- 全局截断到训练集 p0.5–p99.5（[−17.1, −2.0] dB）：截掉亮结构，否决。
- 固定宽窗 [−25, 0] dB（SEN12MS 惯例）：下限与本方案相同，但上限仍截掉 1.5e-3 的像素。
- 逐 patch 标准化：见上。
- 给传统方法的 8 位拉伸版本、多通道输入：不在本决定内，另行研究。

## Consequences

- 常数一旦被使用者依赖就不宜改；要改须新写 ADR。
- 数值范围：SAR 的 z 落在 [−5.2, +8.2]，光学由 uint8 限定在 [−2.78, +6.83]。对训练是否有影响，由基线训练对比实测。
- 出处：地图「Wayfinder：数据集的使用、标注质量与样本难度」下的「决策：SAR 单通道表示与归一化方案」；统计脚本与数字表在分支 `research/sar-normalization`。
