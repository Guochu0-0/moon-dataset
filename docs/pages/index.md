# 月球光学–SAR 配准数据集

嫦娥二号（CE-2）CCD 相机 7 m 数字正射影像（DOM）与 LRO Mini-RF 的 S 波段混合极化 SAR（发射圆极化，接收水平、垂直两路线极化）组成的配准数据集。ROI 分布在月球正面与背面，每个 ROI 切成若干对 512 × 512 像素、7.5 m 的光学–SAR patch，按 ROI 分为训练集、验证集、测试集；验证集与测试集的 patch 带评测真值点。
