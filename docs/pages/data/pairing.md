# 配对特征

## 同一网格

每个 ROI 的光学与 SAR 重叠区影像重采样到同一个 7.5 m 网格：同一坐标系、同一原点、同样的宽高。网格的坐标系、尺寸见各 ROI 页。

## patch

- 光学 patch 是光学重叠区影像上 512 × 512 像素的窗口，按行、列步长 512 排列。
- SAR patch 是 SAR 重叠区影像上 512 × 512 像素的窗口：光学窗口四角经全局仿射映射到 SAR，取映射后四边形的中心定出窗口位置。窗口只随仿射平移，不旋转、不缩放。
- 同号的光学、SAR patch 为一对。每对的两个 patch 都不含 nodata 像素。

文件格式与数值范围见[组织](organization.md#文件)。

## 评测真值点

评测真值点是在单个 patch 对上人工标注的光学–SAR 同名点，用来评测配准精度。它与制作 patch 用的控制点不同：控制点标在整幅重叠区影像上，用来解算仿射。

- 只有验证集与测试集有评测真值点，训练集没有。
- 验证集、测试集里也不是每个 patch 对都有；有的 patch 对上有 7–11 对点，中位数 8。
- 各划分的数量见[统计与分布](statistics.md#划分与数量)，逐 ROI 的数量见各 ROI 页。

文件格式见[组织](organization.md#标签文件)。
