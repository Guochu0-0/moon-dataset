# 各 ROI 的难度

![各 ROI 的点上 RMSE 箱线图，按入射角排列](../assets/difficulty/box-roi.png)

横轴按 SAR 入射角从小到大排。箱为四分位，中间的线是中位数，须为 5–95 分位。纵轴是对数刻度。

<!-- 难度：ROI 表 -->

单位为像素。点表头按入射角、patch 对数或中位数排序。「10–90 分位」一列的横条是对数刻度，竖线为中位数。「沿条带」一列每点一个 patch 对，横轴是 patch 编号，编号沿条带递增；纵轴与横条同一对数刻度。

13 个 ROI 的中位数从 6.9 到 84.3 像素。中位数随 SAR 入射角减小而增大：Spearman 秩相关 −0.76（n = 13，置换检验 p = 0.004）。
