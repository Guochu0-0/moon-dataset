# 成像特征

## SAR：Mini-RF

### 产品 ID

每条条带的产品 ID 也是它的文件名（数据盘上为小写）。按 SIS §4.7.1.1 与表 16 逐段解码，以 `LSZ_02833_2CD_EKU_16S144_V1` 为例：

| 段 | 本例 | 含义 | 取值 |
|---|---|---|---|
| 1 | `L` | 平台 | `L` LRO，`F` Forerunner，`B` 两者 |
| 2 | `S` | 频段 | `S` S 波段，`X` X 波段，`B` 两者，`N` 无 |
| 3 | `Z` | 雷达模式 | `B` Baseline SAR，`I` 干涉，`S` 散射计，`Z` Zoom，`A`、`G`、`C` 定标，`O` 其他 |
| 4 | `02833` | 轨道号（开始采集的那一轨） | 5 位数字 |
| 5 | `2` | 处理级别 | `R` 原始，`1`–`3` Level 1–3 |
| 6 | `CD` | 文件类型 | `PD` 打包数据，`CD` 定标数据（Calibrated Data Record），`S1`–`S4` Stokes 参数，`SC`、`OC` 同向、反向圆极化图像，`CP` 圆极化比图像，`HK` 仪器遥测 |
| 7 | `E` | 投影 | `O` 斜圆柱，`E` 等距圆柱，`P` 极射赤面，`X` 无 |
| 8 | `K` | 分辨率档位 | `A`–`O`，`A` 为 1 ppd，其后每个字母翻一倍；`K` 为 1024 ppd |
| 9 | `U` | 数值类型 | `U` 未归一化浮点，`F` 归一化浮点，`B` 字节 |
| 10 | `16S` | 中心纬度，取整到度 | 2 位数字加 `N` / `S` |
| 11 | `144` | 中心经度，取整到度，东经 0–359 | 3 位数字 |
| 12 | `V1` | 产品版本 | `V` 加数字 |

- 分辨率档位字母与标签不符：67 条条带的档位字母都是 `K`（1024 ppd），产品标签的 `MAP_RESOLUTION` 为 4096 ppd。以标签为准。
- ID 里不含成像时间。成像时间见 GeoTIFF 元数据 `START_TIME`。

### 波段

Mini-RF 为混合极化：发射圆极化，相干接收 H、V 两路线极化。每个产品 4 个 32 位浮点波段，官方 `IMG` 按波段顺序存放（`BAND_SEQUENTIAL`）。

| 波段 | `BAND_NAME` | 物理量 |
|---|---|---|
| 1 | H RECEIVE INTENSITY | ⟨\|E<sub>H</sub>\|²⟩，H 路接收功率 |
| 2 | V RECEIVE INTENSITY | ⟨\|E<sub>V</sub>\|²⟩，V 路接收功率 |
| 3 | CROSS POWER INTENSITY (REAL) | Re⟨E<sub>H</sub> E<sub>V</sub>\*⟩ |
| 4 | CROSS POWER INTENSITY (IMAGINARY) | Im⟨E<sub>H</sub> E<sub>V</sub>\*⟩ |

波段 1、2 是功率；波段 3、4 是交叉功率的实部与虚部，可为负。

### Stokes 参数

SIS §4.3.2.2 的定义，`b1`–`b4` 为四个波段：

```python
S1 = b1 + b2          # 总功率
S2 = b1 - b2
S3 = 2 * b3
S4 = -2 * b4

SC  = 0.5 * (S1 - S4)                        # 同向圆极化
OC  = 0.5 * (S1 + S4)                        # 反向圆极化
CPR = SC / OC                                # 圆极化比
m   = np.sqrt(S2**2 + S3**2 + S4**2) / S1    # 极化度
```

参考值：全月平均 CPR ≈ 0.3，m ≈ 0.6（SIS §4.3.2.2）。

### 格式与投影

- 官方产品为 PDS3 `IMG` + `LBL`，32 位 IEEE 浮点（`PC_REAL`）。空值 `CORE_NULL = 16#FF7FFFFB#`，约 −3.4028 × 10³⁸。
- 等距圆柱投影（`EQUIRECTANGULAR`），`CENTER_LONGITUDE = 180.0`，`CENTER_LATITUDE = 0.0`；月球取球体，半径 1737.4 km；行星中心坐标，东经为正。
- `MAP_RESOLUTION = 4096 <pix/deg>`，`MAP_SCALE = 0.0074031617 <KM/PIXEL>`，即约 7.4032 m。
- 数据盘上只有转换后的 GeoTIFF：像元为 `MAP_SCALE`，nodata 为 `CORE_NULL` 的浮点值，`PRODUCT_ID`、`DATA_SET_ID`、`START_TIME` 等标签字段写在 GeoTIFF 元数据里。

## 光学：CE-2 DOM

### 产品

据 2018 年的数据发布公告：

- 嫦娥二号 CCD 立体相机在 100 km 轨道获取的影像，制成 7 m 分辨率全月数字正射影像（DOM），共 844 幅。
- 每幅由同名的 `tif`、`tfw`、`prj` 三个文件组成。
- 70°S–70°N 用墨卡托投影，两极用极射赤面投影。

该产品属 CE2TMap2015 系列（李春来等，2018）。

从文件读出：

- 单波段 uint8，像元 7 m × 7 m。
- 投影信息的存放方式不统一：有的分幅带旁挂 `.prj`、`.tfw`，有的只把坐标系嵌在 GeoTIFF 里；`raw/ROI_28/ce2/` 下的 G123 分幅，GeoTIFF 里没有坐标系，只有旁挂 `.prj`。

### 分幅命名

分幅文件名形如 `CE2_GRAS_DOM_07m_G203_03N161W_A`，中间两段是分幅号与名义位置：

| 段 | 本例 | 含义 |
|---|---|---|
| 纬度带 | `G` | 见下表 |
| 行号 | `2` | 每条纬度带分南北两行，各 7°，`1` 在北、`2` 在南 |
| 列号 | `03` | 从 180°W 起向东编号，每幅的经度宽随纬度带不同 |
| 名义纬度 | `03N` | 本幅中心附近的纬度，取整到度 |
| 名义经度 | `161W` | 本幅中心附近的经度，取整到度 |

按这套规则从名字算出的经纬范围，与数据集用到的全部分幅由 geotransform 反算的范围相差不超过 0.03°。

### 分带墨卡托参数
