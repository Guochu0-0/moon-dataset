图表沿用 Git 修订 `0388796` 的历史划分。图中的「验证集」和「测试集」分别指原验证集和原测试集，所示样本现均归入[测试集](statistics.md#划分与数量)。

原验证集与原测试集的 10、25 分位几乎相同。原测试集的 90 分位是原验证集的 1.7 倍。原测试集 7 个 ROI 里有中位数最大的两个，ROI_054 与 ROI_007。
