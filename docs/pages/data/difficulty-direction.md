# 错位的方向

x 轴近似 SAR 的距离向，y 轴近似方位向。点上 RMSE 可以按坐标轴拆开：

![RMSE_x = √( (1/N) Σ dᵢ,ₓ² )，RMSE_y = √( (1/N) Σ dᵢ,ᵧ² )](../assets/difficulty/formula-xy.svg){.formula}

两者的平方和等于点上 RMSE 的平方。

![各 patch 对的平均错位，x 与 y 两轴同比例](../assets/difficulty/dxdy.png)

每点一个 patch 对，坐标是这个 patch 对上各个 d 的平均。两轴比例相同。

| 分位（n = 1605） | 10 | 25 | 50 | 75 | 90 | 99 |
|---|---|---|---|---|---|---|
| RMSE_x（像素） | 6.6 | 11.6 | 27.1 | 58.2 | 104.3 | 209.6 |
| RMSE_y（像素） | 1.0 | 1.2 | 1.7 | 2.4 | 3.8 | 9.5 |

1605 个 patch 对中，每一个都是 RMSE_x 大于 RMSE_y。RMSE_y 有 84% 低于 3 像素，与每轴约 1 像素的标注误差相差不大。

x 方向的错位有正有负：按 patch 对内的平均，52% 的 patch 对 SAR 点在光学点右侧，48% 在左侧。

同一 patch 对内，各点的 x 错位也不相同。ROI_020 的 patch 39 里，9 对点的 x 分量从 −52.7 到 +22.1 像素，y 分量都在 ±3.1 像素以内。
