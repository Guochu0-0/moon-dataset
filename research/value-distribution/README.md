# 光学与 SAR 各波段及派生量的数值分布

issue #36「统计：光学与 SAR 各波段及派生量的数值分布」的产出，供「决策：SAR 单通道表示与归一化方案」使用。

- `stats.py`：`collect` 读全部 9862 对 patch（Train 7907 / Val 825 / Test 1130，不含 ROI_060），缓存到 `work/research/value-distribution/`；`report` 由缓存写出下面的表和图。
- `tables.md`：全部数字（概况、光学阴影、各量分位数、ROI 间差异、逐 ROI 表）。
- `summary.json`：同一批数字，机器可读。
- `histograms.png`：各量分布，三个划分叠画。
- `position_maps.png`：零值、b1/b2 负值在 patch 内出现的位置。
- `between_roi.png`：逐 patch 中位数按 ROI 的箱线图。

零值、负值、无定义的比例是全部像素的精确计数；分位数与直方图由每 patch 固定抽 2048 个像素算得。波段与派生量的定义见 `docs/pages/data/imaging.md`。

复现：`python research/value-distribution/stats.py collect && python research/value-distribution/stats.py report`（本机约 10 分钟，数据根写死在脚本顶部 `DATASET_ROOT`）。

## 结论

**1. 没有 nodata，也没有填充值。** 9862 对 patch 里，SAR 没有一个像素四个波段全为零，没有 Mini-RF 填充值（−3.4e38），也没有 NaN；光学没有灰度 0。预处理不需要处理掩膜。

**2. 功率类的量实际上都是正数。** b1、b2、S1、SC、OC 的非正值只占约 2e-7（Train 共 469 个像素），64–93% 落在 patch 的四条边上（主要是第 0 列和第 511 列），像是重采样在边缘的过冲。取 dB 前把下限夹到一个很小的正数就够了，不会丢信息。CPR 和 m 在同样那几个像素上无定义；m > 1 的像素约 1e-6。

**3. 负值只来自交叉功率。** b3 约 37% 为负、b4 约 91% 为负，两者都集中在 0 附近（p1–p99 约 ±0.1）。这是物理量的符号，不是缺陷。

**4. 取 dB 后分布紧凑、近似单峰，三个划分基本一致。** S1 dB 的 Train 分位：p0.5 −17.1、p1 −16.6、p50 −11.2、p99 −3.2、p99.5 −2.0，最大 +9.9；p0.5–p99.5 的跨度约 15 dB。右尾长（亮点、朝向雷达的坡面）。Val 比 Train 整体亮约 0.5 dB，Test 与 Train 接近。CPR 的中位约 0.49，约 9.5% 的像素 CPR > 1。

**5. 条带之间有明显的整体亮度差，但和 patch 内的起伏相当。** 逐 patch 的 S1 dB 均值按 ROI 平均后，从 −13.2 到 −9.1 dB（Train），ROI 间标准差 1.0 dB，与 ROI 内的标准差 1.1 dB 相当；单个 patch 内 S1 dB 的标准差约 2.2 dB。所以全局常数归一化会让不同 ROI 的 patch 整体偏移约 ±1–2 dB，逐 patch 归一化能把它消掉，但也会把同一 ROI 内真实的亮暗差消掉。这一条是「全局还是逐 patch 归一化」的直接依据（见调研票 #35）。

**6. 光学的 ROI 差异比 SAR 大得多。** 逐 patch 均值的 ROI 间标准差为 20 个灰度级，ROI 内只有 9；ROI 中位灰度从 35 到 111。直方图的双峰就是两类 ROI：一类暗且对比度极低（ROI_021、038、057、058、061、062、074，Test 的 ROI_059），IQR 只有 3–6 个灰度级，抽样里只出现 53–75 个不同灰度；另一类中位灰度 70–110。这些低对比度 ROI 对传统方法最不利，也是「给传统方法的版本」要拉伸光学的理由。

**7. 光学有阴影饱和，只在训练集。** 灰度 1 是阴影里压到底的黑，没有任何地物信息，而 SAR 在同一处照样能看到地形。它占 Train 像素的 0.36%，集中在 ROI_016（5.6%）、ROI_027（4.1%）、ROI_003、025、015；约 69 个 patch 的阴影超过 10%，17 个超过 50%（最多达 97%）。Val 和 Test 没有。它影响两件事：光学归一化时要不要把灰度 1 当成缺失；样本难度里应当有一项「光学阴影占比」，这些 patch 几乎无法配准。

**8. 光学上端几乎不饱和。** 灰度 255 只占约 7e-5（Train）。
