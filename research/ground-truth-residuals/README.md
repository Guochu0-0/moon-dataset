# 评测真值点在 patch 内的偏移与拟合残差

issue #40「统计：评测真值点在 patch 内的偏移与拟合残差」的产出，方法取舍见该票评论与调研笔记
「没有重复标注时，估计人工同名点标注误差的方法」（#39，分支 `research/annotation-error-methods`）。

- `collect.py`：读数据盘上 1955 个验证集、测试集 patch 与 13 对重叠区影像的地理变换，算出每个 patch
  的光学、SAR 窗口左上角，写 `windows.csv`。三道校验全部通过：窗口是整数像素、光学窗口在 512 网格上；
  由控制点全局仿射按 `moondata.geometry.sar_window` 推出的 SAR 窗口逐个相等；ROI_037、054、070
  与 `work/windows/` 里当年的窗口记录逐条一致。需要 GDAL（`newest` 环境）。
- `analyze.py`：只读仓库（真值点、控制点、元数据、`windows.csv`），写出下面这些文件。
- `tables.md`：全部数字。`summary.json`：同一批数字，机器可读，含完整的经验变异函数。
- `patches.csv`：逐 patch 的偏移、离散程度、仿射残差、跨度与检验 p 值（1605 行）。
- `outliers.csv`：3 倍规则剔除的 424 个点，含学生化残差。
- `residuals.png`、`tilt.png`、`variogram.png`、`offsets.png`、`offset_maps.png`。

复现：

```sh
PYTHONPATH=src conda run -n newest python research/ground-truth-residuals/collect.py   # 需数据盘，约 1 分钟
PYTHONPATH=src conda run -n newest python research/ground-truth-residuals/analyze.py   # 只读仓库，约 1 分钟
```

记号：一对点的错位 `d = SAR 点 − 光学点`（patch 内像素，1 像素 = 7.5 m）。x 近似 SAR 的距离向
（13 个 ROI 的视方位角都约为 90° 或 270°），y 近似方位向。下面的「标注误差」都指一对点的**合成**误差，
即光学、SAR 两次点击误差之和，每轴计；若两侧一样准，单侧点击误差再除以 √2。

## 结论

**1. 残差强烈各向异性：x 是 y 的约 3 倍，但多出来的部分是错位本身，不是标注。** 逐 patch 仿射
残差剔除粗差后 σ̂x = 3.47、σ̂y = 1.21 像素（95% 区间 3.41–3.52、1.19–1.23；1605 个 patch、
每分量 7792 个自由度），x、y 残差不相关（ρ = 0.02）。判断 x 多出来的是错位的理由：σ̂y 在 13 个 ROI
之间几乎不变（1.03–1.31），σ̂x 从 1.69 到 4.22 随 ROI 变化，而且入射角越小 σ̂x 越大（Spearman
−0.68，p = 0.01），y 与入射角无关（0.10，p = 0.73）。标注员的手不会知道入射角，地形引起的距离向
位移却正比于 cot θ。x 的空间结构（第 3 条）也说明它是一个连续的场。

**2. 标注误差的上界：松的约 1.2 像素，紧的约 0.9–1.0 像素（每轴，两侧合成），只能从 y 读出。**

- 松的：仿射残差 σ̂y = 1.21 像素。
- 紧的：y 的经验变异函数最短的几档，h ≈ 25 像素时 γy = 0.91 像素²（43 对，相对标准误约 20%），
  39 像素时 1.28 像素²。只拟合短距离段外推：线性（h ≤ 60/100/150）得 nugget 0.69/0.97/1.21 像素²，
  二次得 0.96/1.17/1.35 像素²，Cressie–Hawkins 稳健估计与之相差不到 0.1。
- 全距离模型（指数、球状、高斯，拟合范围 250–2000 像素）的 nugget 为 1.10–1.72 像素²，**不比仿射残差紧**：
  γy 在 100 像素以内还在缓慢上升（0.9 → 1.5），全距离模型把这段短程结构当成了 nugget。
  所以紧的上界取短距离外推，约 0.83–1.10 像素，中间约 0.95 像素。
- 这仍是上界：比最短点距（约 20 像素）更小尺度上的真实错位也算在里面。
- x 分量读不出标注误差：γx 从 25 像素的 4.8 像素² 起一路陡升（约 h^1.5），全距离模型的 nugget
  在 0 到 16 像素² 之间乱跳；只有短距离二次外推（h ≤ 60）得 0.92 像素²，与 y 一致，但只靠几十对点。
  若假定标注误差各向同性，x 也用 y 的数。
- 若两侧一样准，单侧点击误差上界约 0.65–0.85 像素，也就是 5–6 m。

**3. 残差与点在 patch 内的位置、与 ROI、与视向都没有明显关系（y 分量）。** 按到 patch 中心的距离分组，
σy 在 1.16–1.25 之间；σx 在离中心超过 320 像素（角上）时从 3.5 升到 4.15，符合仿射在角上外推错位场
不够准。视向只有 2 个 ROI 是 RIGHT，看不出差别。同一 patch 内与跨 patch 的点对，在相同距离上
γ 一致（x、y 都是），所以**没有逐 patch 的系统标注偏差**，patch 边界上也没有断层。

**4. 粗差：3 倍规则剔除 424 个点，但大多不是标错。** 纯高斯下期望约 68 个。其中 126 个由 y 触发
（只看 y 期望约 34 个），剔除后 y 的超额峰度从 10.1 降到 −0.15，这批可以视为真正的标注粗差（y 残差
中位 3.6 像素、最大 16 像素）。另外 298 个只由 x 触发（x 残差 2.5–28 像素），多数应是仿射吃不掉的
地形错位，不能算标注错误。逐 patch 剔除 0/1/2/3 个点的 patch 数为 1254/288/53/10。

**5. 残余错位很大，集中在 x。** patch 中心处的错位 |dx| 的中位为 25 像素，95 分位 140 像素（约 1 km）；
|dy| 的中位为 1.0 像素，95 分位 4.7 像素。测试集比验证集更难（|dx| 中位 27.8 对 21.2 像素）。ROI 之间
差别很大：ROI_059 的 dx 5–95% 只有 −9 到 8 像素，ROI_054 是 −145 到 189、ROI_007 是 −121 到 204。
`offset_maps.png` 上 dx 沿条带成片连续变化、正负交替，看起来像地形。数据集的 SAR 窗口只按控制点的
全局仿射放置，这部分错位留在了 patch 对里。

**6. 一个 patch 用一个平移向量概括不了（x 分量），y 分量可以。** 错位沿 patch 对角线从一角到另一角的
变化（跨度）中位为 29 像素，95 分位 124 像素；几乎全在 x（x 分量中位 29 像素，y 分量中位 3.2 像素）。
零假设（真实错位是平移，只有 σ̂ 的噪声）下跨度的中位只有约 8 像素。79% 的 patch 超过零假设的
95 分位；χ² 检验在 p < 0.01 下拒绝「纯平移」的有 72%。一部分来自全局仿射本身的 x 向比例差（13 个 ROI
在一个 patch 上造成 3.7–81.7 像素的 x 跨度，ROI_006 最大，SAR 在 x 向约缩了 8%），但扣掉它以后仍有
67% 的 patch 超过零假设（p < 0.01 下拒绝 62%）：patch 内的斜率本身也随地形变化。y 的跨度与噪声水平相当。
扣掉仿射后 x 仍有约 3.5 像素的非仿射残差，所以即便用逐 patch 仿射描述，x 也还有剩余。

## 对地图其他部分的影响

- 评测指标的精度：标注误差（每轴合成）上界约 0.9–1.2 像素，是任何配准精度指标在 7.5 m 网格上的分辨下限的量级。
- 评测方式：patch 内 x 向错位变化几十像素，拿「一个平移」或「一个全局单应」当真值会与真值点自相矛盾，
  评测宜在真值点上逐点算误差。
- 训练集的样本难度：x 向错位场在几百像素的尺度上就有变化（γx 在 100 像素处已达 36 像素²），而每个 ROI 只有
  约 30 个控制点、点距数千像素，用控制点残差沿条带插值多半估不出来。x 向错位与入射角的关系提示它来自地形，
  用 DEM 按 h·cot θ 预测也许可行，未验证。
- 盲重标：y 已给出约 0.95 像素的紧上界；盲重标的价值在于给出不依赖错位场假设的下端锚点，并检验
  「x 的标注误差与 y 相同」这一假定（x 无法从本数据自身读出）。
