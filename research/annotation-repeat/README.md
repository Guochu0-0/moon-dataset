# 无意重标：锚定标注误差（issue #41，地图 #34）

原计划组织一次小样本盲重标，给标注误差一个不依赖残余错位形状假设的锚点。查数据时发现不必：
评测真值点（ArcGIS，逐 patch）与控制点（ENVI，整幅重叠区影像）是作者先后两次独立标的，
标评测真值点时没有参考控制点，而两者有 124 处落在同一地物上（光学侧相距 < 5 像素；随机
对照只有 0.7 处）。这就是一份现成的同一人重复标注，覆盖全部 13 个验证、测试 ROI。

运行：`python research/annotation-repeat/repeat.py`（`moon-dataset` 环境，只读仓库内文件）。
数字见 `tables.md`，逐对数据见 `pairs.csv`，方法写在脚本开头的文档字符串里。

## 结论

- 一次标注（光学、SAR 两次点击合成）每轴的误差：**σy ≈ 0.9–1.0 像素，σx ≈ 1.1–1.4 像素**。
  r 取得越严，越确定是同一处，σx 越小（r < 1 时 1.14 ± 0.15）；放宽后多出来的一部分是
  残余错位在 r 上的变化，这在 x 上最明显。
- y 与「统计：评测真值点在 patch 内的偏移与拟合残差」的紧上界（变异函数，约 0.95）一致：
  那个上界基本就是标注误差本身，没有明显偏高。
- x 第一次有了实测值，略大于 y，但不到 y 的 1.5 倍；此前「x 与 y 相同」的假定大体成立，
  x 略差。

## 局限

- 同一人两次标注，测不到此人稳定的系统偏好。
- 两侧都重点过，光学侧与 SAR 侧的点击误差分不开。
- 两次标注之间 x 有约 −0.6 到 −1.2 像素的系统差（中位数），来自两套工具或两次习惯的差别，
  不影响 σ；评测真值点只用一套，这个差对评测无影响。
- 两次同样准、相互独立是假定；控制点是整数像素，量化方差已扣。
