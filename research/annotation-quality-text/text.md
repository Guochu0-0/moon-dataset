# 标注质量

评测真值点由人工标注，每一对点都带有标注误差。在评测真值点上量出的配准误差，同时包含算法误差和标注误差；知道标注误差有多大，才能客观地判断算法的结果。

## 误差模型

一对评测真值点，光学坐标为 p，SAR 坐标为 q，两者之差

    d = q − p = g(p) + e

- g(p)：该位置上光学与 SAR 之间真实存在的错位；
- e：标注误差，即 SAR 侧与光学侧两次点击误差之差。

标注误差的大小用 σ 表示：e 在一个坐标轴上的标准差，单位为像素（1 像素 = 7.5 m）。x 轴近似 SAR 的距离向，y 轴近似方位向。

每个点只标注一次，单个点上的 g 与 e 分不开。每种估计方法都要借助关于 g 或 e 的某种假设把两者分开；g 中没被分出去的部分会算进 σ，这时得到的是 σ 的上界。

## 估计方法

### 最小二乘拟合残差

<details>
<summary>例子</summary>

一个 patch 上有 8 对点。如果真实错位在 patch 内恰好是一个仿射变换，用最小二乘拟合出这个仿射后，剩下的残差只来自标注误差。如果真实错位比仿射复杂，残差里还带着没拟合掉的部分，由残差算出的 σ 就偏大。

〔图：一个 patch 上的 8 对点、错位箭头与拟合的仿射〕

</details>

**原理**　在每个 patch 内用仿射变换近似真实错位 g，把拟合后的残差当作标注误差的样本。g 中仿射描述不了的部分也留在残差里，所以估计值是 σ 的上界。点配准文献把这种残差称为配准点误差（fiducial registration error，FRE）。

**计算**　对每个 patch、每个坐标轴分别拟合

    d = a·x + b·y + c

x、y 是光学点在 patch 内的坐标。跨 patch 汇总残差平方和 RSS：

    σ̂² = Σ RSS / Σ (N − 3)

N 是该 patch 的点数。汇总前迭代剔除粗差：每轮找出学生化残差最大的点，超过 3 就剔除并重新拟合该 patch，直到没有点超过 3。

```python
def fit_affine(p, d):
    """p：光学点 (N, 2)；d：偏差 q − p (N, 2)。返回残差与杠杆值。"""
    X = np.column_stack([p, np.ones(len(p))])
    coef, *_ = np.linalg.lstsq(X, d, rcond=None)
    hat = np.einsum("ij,jk,ik->i", X, np.linalg.pinv(X.T @ X), X)
    return d - X @ coef, hat


def pooled_sigma(residuals):
    """residuals：各 patch 的残差 (N, 2)。返回 (σ̂x, σ̂y)。"""
    rss = sum((r**2).sum(axis=0) for r in residuals)
    dof = sum(len(r) - 3 for r in residuals)
    return np.sqrt(rss / dof)
```

**结果**　数据是验证集、测试集中有评测真值点的 1605 个 patch，共 13031 个点，每个 patch 7–11 个点。剔除 424 个点后，每轴自由度为 7792。

| | σ̂x（像素） | σ̂y（像素） |
|---|---|---|
| 剔除前 | 4.44 | 1.42 |
| 剔除后 | 3.47（3.41–3.52） | 1.21（1.19–1.23） |

括号内为 95% 置信区间。

剔除的点中有 126 个由 y 残差超限触发，约占全部点的 1%。剔除这些点后，y 残差的超额峰度由 10.1 降到 −0.15，这 126 个点是标注粗差。评测真值点文件保留原样。

13 个 ROI 各自的 σ̂y 在 1.03–1.31 之间；σ̂x 在 1.69–4.22 之间，并随 SAR 入射角减小而增大（Spearman 秩相关 −0.68，p = 0.01；σ̂y 为 0.10，p = 0.73）。标注误差与入射角无关，x 残差中多出的部分是仿射描述不了的错位，推测来自地形，未经验证。本方法因此只给出 y 方向的上界：σ̂y = 1.21 像素。

### 变异函数

<details>
<summary>例子</summary>

沿一条线标注若干点。真实错位 f(s) 随位置平滑变化，每个点的读数 r = f(s) + e 还带着这一次的标注误差。相距 h 的两个点：

    r₂ − r₁ = [f(s + h) − f(s)] + (e₂ − e₁)

两点越近，第一项越小；两点挨在一起时，差里只剩两次标注误差。把相距约为 h 的所有点对的 ½(r₂ − r₁)² 取平均，记作 γ(h)。画出 γ(h) 并外推到 h = 0，截距就是 σ²。

〔图：左，错位曲线 f(s) 与带误差的读数；右，γ(h) 与外推到 h = 0 的截距〕

</details>

**原理**　若真实错位在空间上连续、标注误差在点与点之间相互独立，则变异函数

    γ(h) = ½ E[(rᵢ − rⱼ)²]，  |pᵢ − pⱼ| ≈ h

在 h → 0 时趋于 σ²。这个极限在地统计中称为块金值（nugget）。最近的点对也相距约 20 像素，块金值只能由短距离段外推得到；比最短点距更小尺度上的真实错位变化也会计入块金值，所以估计值是 σ² 的上界。

**计算**

1. 按 patch 窗口在重叠区影像上的位置，把评测真值点换到重叠区影像坐标（光学 P、SAR Q），取对全局仿射的残差 r = Q − G(P)。G 是该 ROI 由控制点解算出的全局仿射。
2. 在同一 ROI 内取全部点对，按光学侧距离 h 分档，每轴计算 γ(h)；13 个 ROI 的点对合并。使用剔除粗差后的 12607 个点。
3. 取 h ≤ 60、100、150 像素的档，分别作线性、二次加权拟合，截距即块金值，共 6 个估计。

```python
from scipy.spatial.distance import pdist

h = pdist(P)                            # 点对的光学侧距离
half_sq = 0.5 * pdist(r[:, [1]]) ** 2   # y 分量的 ½(rᵢ − rⱼ)²
b = np.digitize(h, edges) - 1
gamma = np.bincount(b, half_sq) / np.bincount(b)
```

**结果**　y 分量最短一档 h ≈ 25 像素时 γ = 0.91 像素²（43 对），39 像素时为 1.28 像素²（208 对）。6 个外推估计的块金值在 0.69–1.35 像素²之间，即 σ̂y = 0.83–1.16 像素。

x 分量的 γ 在 25 像素处已达 4.8 像素²，随距离陡升，外推截距定不下来。

同一 patch 内的点对与跨 patch 的点对，在相同距离上 γ 一致，x、y 都是如此：不存在逐 patch 的系统标注偏差。

### 重复测量

<details>
<summary>例子</summary>

同一个撞击坑被同一个人先后独立点了两次。两次都量的是同一处的错位，两次读数之差与错位无关，只来自两次标注误差。

〔图：同一个撞击坑上的两次点击〕

</details>

**原理**　同一处地物独立标注两次，两次偏差之差 δ 中真实错位相消，只剩两次标注误差之差。两次标注同样准、相互独立时，每轴 Var(δ) = 2σ²。这种方法不需要对真实错位作任何假设；但同一人稳定的系统偏好在两次标注中都会出现，在差中相消，所以它估计的是标注误差的随机部分。

**计算**　控制点与评测真值点由同一人先后独立标注：控制点用 ENVI 标在整幅重叠区影像上，坐标为整数像素；评测真值点用 ArcGIS 逐 patch 标注，标注时没有参考控制点。两套点中有一部分落在同一处地物上。

1. 把评测真值点换到重叠区影像坐标。
2. 光学侧相距小于 r 的评测真值点与控制点配成一对，δ = d_评测真值点 − d_控制点。
3. 按 3 倍 MAD 剔除离群的配对。
4. σ̂² = (s²_δ − 2/12) / 2，s²_δ 是 δ 的样本方差，2/12 是控制点光学、SAR 坐标取整带来的量化方差；标准误取 σ̂ / √(2(n − 1))。

```python
dev = delta - np.median(delta, axis=0)
mad = 1.4826 * np.median(np.abs(dev), axis=0)
keep = np.all(np.abs(dev) < 3 * mad, axis=1)
s2 = delta[keep].var(axis=0, ddof=1)
sigma = np.sqrt((s2 - 2 / 12) / 2)
```

**结果**　13 个验证、测试 ROI 共有 397 个控制点、13031 个评测真值点，光学侧相距 5 像素以内的配对有 124 对。把控制点整体随机平移后，同样半径内平均只有 0.7 对（200 次，最多 5 对），所以这些配对几乎都是同一处地物。

| r（像素） | 配对 | 剔除 | σ̂x（像素） | σ̂y（像素） |
|---|---|---|---|---|
| < 1 | 31 | 1 | 1.14 ± 0.15 | 0.93 ± 0.12 |
| < 2 | 69 | 3 | 1.32 ± 0.12 | 0.88 ± 0.08 |
| < 3 | 113 | 6 | 1.42 ± 0.10 | 1.03 ± 0.07 |
| < 5 | 124 | 6 | 1.40 ± 0.09 | 1.04 ± 0.07 |

± 为标准误。r 越大，两次标注越可能不在同一处，δ 中混入两处错位的差，x 上最明显。取 r < 1 的结果：σ̂x = 1.14 ± 0.15，σ̂y = 0.93 ± 0.12 像素。

两次标注之间有系统差：δ 的中位数 x 为 −0.6 到 −1.2 像素，y 为 −0.1 到 −0.5 像素，来自两套工具或两次操作习惯的差别，不影响 σ̂。

光学侧与 SAR 侧的点击误差分不开。两次标注相互独立、同样准，是本方法的假定。

**出处**

- Bland J. M., Altman D. G. Measurement error. *BMJ*, 313:744, 1996. doi:10.1136/bmj.313.7059.744
- Castillo R. et al. A framework for evaluation of deformable image registration spatial accuracy using large landmark point sets. *Physics in Medicine and Biology*, 54(7), 2009. doi:10.1088/0031-9155/54/7/001
